# QA Tests - Cypress

Projeto simples de estudos em automação de testes utilizando Cypress.

## Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de Qualidade de Software (QA/QE), com o objetivo de aprender conceitos básicos de automação de testes.

## Testes realizados

Atualmente o projeto possui três de login:

- Login com usuário válido
- Tentativa de login com senha incorreta
- Tentativa de login com campos vazios

## Tecnologias utilizadas

- JavaScript
- Node.js
- Cypress
- Git
- GitHub
